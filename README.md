# 🌍 Last Breath — VitalEarth
### Earth's Vital Signs. Live.

**VitalEarth** is an environmental awareness dashboard designed to bring Earth's vital signs into one place. It presents environmental indicators related to climate change, deforestation, ocean health, and air quality to help users explore the challenges facing our planet.


## 🌱 Overview

Climate change, forest loss, ocean degradation, and air pollution are interconnected environmental challenges that affect ecosystems and human life.

Environmental information is often spread across different sources, making it difficult to understand the bigger picture.

**Last Breath — VitalEarth** brings these environmental indicators together in a unified dashboard, making complex environmental information easier to explore and understand.

Its mission is simple: make the state of our planet more visible and encourage informed environmental awareness.



## 🚨 Problem Statement

Our planet faces several critical environmental challenges:

- 🌡️ **Climate Change:** Rising global temperatures and increasing greenhouse gas concentrations.
- 🌳 **Deforestation:** Loss of forest cover and degradation of natural habitats.
- 🌊 **Ocean Degradation:** Ocean warming, acidification, and coral bleaching.
- 🌫️ **Air Pollution:** Poor air quality that can threaten human health.
- 📊 **Fragmented Information:** Environmental indicators are distributed across different monitoring platforms.

There is a need for a unified, accessible platform that helps people understand these environmental changes.



## 💡 Our Solution

VitalEarth provides a centralized environmental dashboard that organizes key indicators into four major areas:

1. **Climate Monitoring** — Explore warming trends and climate indicators.
2. **Forest Monitoring** — Understand forest loss and deforestation alerts.
3. **Ocean Monitoring** — Examine ocean temperature, acidity, and coral bleaching indicators.
4. **Air Quality Monitoring** — Compare air-quality conditions across selected cities.

The platform presents these indicators in a visual format to support environmental education, awareness, and exploration.



## ✨ Key Features

### 🌎 1. Global Environmental Overview
A unified overview of environmental indicators and an overall Earth health score displayed by the dashboard.

Present environmental indicators and trends through a dashboard designed to make information easier to interpret.

The application includes a presentation control for showcasing its environmental dashboard.

## ⚙️ How It Works

**Step 1 — Explore the Dashboard**

**Step 2 — Select an Environmental Category**

**Step 3 — Examine the Indicators**

Review the environmental metrics, trends, and alerts displayed in the selected module.

**Step 4 — Understand the Environmental Impact**

Use the presented information to explore the connections between environmental changes and planetary health.

**Step 5 — Raise Awareness**

Use the dashboard as a visual resource for environmental education, presentations, and sustainability discussions.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/sandhya-it/Last-Breath.git
```

**2. Navigate to the project directory**

```bash
cd Last-Breath
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🔐 Data Transparency

Environmental dashboards are most useful when their data can be verified.

Future iterations should clearly distinguish between live measurements, historical records, estimates, and illustrative demonstration values.

Where applicable, each indicator should include its source, measurement unit, update time, and relevant limitations.
